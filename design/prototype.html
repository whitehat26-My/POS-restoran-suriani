Design prototype — the real menu, a pretend restaurant. All three surfaces on one page, wired to each other: order on the phone and it appears on the counter and prints a kitchen slip. The menu is generated from the same file the live system serves, so the dishes and prices here are the real ones. Everything else is make-believe — no server, no database, and the orders vanish when you reload. The working system is apps/menu/ and apps/pos/; run pnpm dev.

Satu sistem token

Setiap warna dan saiz teks datang dari satu set token CSS. Menukar jenama restoran lain hanya perlu tukar token — bukan reka semula.

Wang dalam sen

Semua harga disimpan sebagai integer sen, bukan nombor perpuluhan. Inilah sebab jumlah bil tidak pernah tersasar satu sen.

Kod QR ialah rahsia

QR meja tidak mengandungi nombor meja. Ia membawa token rawak, supaya tiada sesiapa boleh menghantar pesanan ke meja orang lain.

Dwibahasa dari awal

Setiap teks datang dari lapisan terjemahan, bukan ditulis terus dalam paparan. Menambah bahasa ketiga kemudian hanya kerja mengisi.
